# SAP-ABAP-Purchase-Order-ALV-Report
Classical SAP ABAP ALV Report for displaying Purchase Order Header, Item, and Vendor Information using EKKO, EKPO, and LFA1 tables.
## Technologies & Concepts
- ABAP Programming
- Open SQL
- INNER JOIN
- Internal Tables
- Work Areas
- SELECT-OPTIONS
- ALV Grid Display
- ALV Field Catalog
- Custom Column Headings
- ALV Layout Customization
- Row Coloring
- Automatic Column Width Optimization
- ALV Header using REUSE_ALV_COMMENTARY_WRITE
- Sequential Numbering
## Main Features
1. Search Purchase Orders using EBELN.
2. Retrieve Purchase Order Header Data.
3. Retrieve Item Details.
4. Retrieve Vendor Information.
5. Generate Sequential Numbers.
6. Highlight Rows Based on Net Price.
7. Customize ALV Columns and Headings.
8. Optimize Column Widths.
9. Display a Custom ALV Header.
